# 네온 표현 가이드 (2026-10-24 학습)

하율 피드백: 1차 네온 시계(흰 글자 + 분홍 테두리 + 하늘색 3D 그림자, 4초마다 깜빡)가 "완전 짜침".
→ 실제 네온 사인 제작 원칙 + 웹 네온 표현 기법을 조사해 정리. 네온이 들어가는 화면은 이 규칙을 따른다.

## 1차가 짜쳤던 이유
| 1차 | 실제 네온 |
|---|---|
| 굵은 Outfit 800을 **채우고** 분홍 `text-stroke`로 테두리 | 네온은 유리관 **한 줄(모노라인)** — 속이 꽉 찬 글자도, 윤곽선 글자도 아님 |
| `6px 6px` 하늘색 오프셋 그림자(스티커 3D) | 빛은 사방으로 퍼짐 — 한쪽으로 밀린 그림자는 '인쇄물' 느낌 |
| 밝은 크림 배경 위에 바로 | 네온은 어두운 면(아크릴 판·벽) 위에서만 빛나 보임 |
| 4초마다 전체가 깜빡 | 계속 깜빡이면 고장 난 간판·싸구려 느낌. 켤 때 한 번 + 아주 가끔 한 글자만 |

## 3차 수정(2026-10-24)
2차(가는 Pretendard + 검은 아크릴 판)도 "완전 안 예쁨" — 깜빡임만 합격. 사이트 정체성(Outfit 800 시계 글씨)을 버리면 안 됨 → 같은 글씨를 네온관 윤곽선(속 빈 관 + 바깥 빛)으로, 판 없이 배경 위에. 큰 검은 판처럼 사이트 스티커 톤과 동떨어진 덩어리 금지.

## 원칙
1. **관 = 모노라인**: 획 굵기가 일정하고 끝이 둥근 중간 굵기. 가는 헤어라인·컨덴스드·장식 많은 글꼴은 실패. (사이트: Pretendard Variable 250~300)
2. **속은 하얗게, 겉은 색**: 관 중심은 흰색에 가까운 색(`#fff` 72% + 네온색), 바깥으로 갈수록 색이 진해지다 옅어짐.
3. **빛은 겹으로**: 관 바로 옆(작은 블러·진하게) → 번짐(중간) → 벽에 퍼진 빛(크게·옅게). 단위는 em이라 글자 크기 따라 같이 커짐 (`--ne-glow`).
4. **판에 붙인다**: 거의 검은 남보라 아크릴 판 + 위쪽 약한 반사 + 판 안쪽으로 번진 색 + 판 밖 벽에 비친 빛 + 모서리 볼트(스탠드오프) 4개.
5. **깜빡임 없음**(2026-10-24 하율: 깜빡임 없애 달라) — 네온 시계는 항상 켜진 채로.
6. **색은 실제 네온관 색만**: 핑크·레드·오렌지·옐로·그린·아이스 블루·블루·퍼플·웜 화이트. 형광 그라데이션·무지개 금지.
7. **성능**: 그림자 애니메이션 금지(모바일에서 무거움) — 깜빡임은 opacity·color만.

## 사이트 적용 위치
- `style.css` '네온 시계(뽑기 전설 효과)' 구간: `html[data-ckfx=neon]`, 색은 `html[data-neon=…]` → `--ne`.
- 색 목록 `att-rewards.js NEON`, 고르기 `neonPick()` — 꾸미기 미리보기 + 뽑기 '내 효과'. 저장은 기기별 localStorage `sg_neon_c`.
