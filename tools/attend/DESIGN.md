# 출석 체크 디자인 노트 (학습 기록)

2026-10-23 하율 지시: "출석 보상 늘리고 디자인 더 찾아서 학습한 다음 적용". 출석 기능을 고칠 땐 이 문서를 먼저 읽을 것.

## 조사한 것과 배운 점

### 듀오링고 연속 기록 (가장 많이 참고)
- **기념일만 크게.** 평소엔 숫자만 올라가고, 7·30·100·365일 같은 날에만 화면 전체 축하를 띄운다.
  - 축하 애니메이션 하나를 다시 만든 것만으로 신규 사용자의 7일 뒤 잔존율이 1.7% 올랐다고 한다.
- **기념일 = 캐릭터가 '파워 업'.** 숫자 풍선(정적인 축하)은 "귀엽지만 힘이 없다"고 버렸다. 대신 듀오가 불사조로 변신하는 '진화' 연출을 썼다.
  - 우리 적용: 불꽃 색이 기록에 따라 바뀐다.
- **방패(스트릭 프리즈).** 자동으로 지급되고, 자동으로 쓰인다.
  - 달력에는 지켜 준 날을 다른 표시로 남긴다.
  - 최대 2개. 2개까지 쌓을 수 있게 했더니 쉬는 날은 늘지 않고 활동은 늘었다고 한다.
- **완벽한 연속.** 방패를 안 쓰고 이어 간 기록을 따로 표시한다. 보이는 차이는 불꽃의 금빛 후광 하나뿐이다.
- **개근 주(Perfect Week).** 한 주의 요일 아이콘이 이어진 띠 하나로 합쳐진다.
- **보상은 두 종류를 섞음.**
  - 쓸모 있는 것: 방패 등
  - 희소한 것: 전용 아이콘, 수집품
- **지위가 보이게.** 오래 이어 간 사람은 순위·이름 옆에 기록이나 표시가 붙는다.
- **친구와 함께.** 친구 연속 기록이 하나라도 있으면 그날 공부를 끝낼 확률이 22% 높다고 한다.
- **처음 7일이 가장 깨지기 쉽다.** 초반 보상 간격을 촘촘하게 둔다(3·5·7일).

### 연속 기록 설계 원칙
- 무엇을 하면 기록이 이어지는지 분명하게 한다. 끊기는 조건도 분명하게 한다.
- 숫자를 늘 보이게 하고, 다음 목표까지의 진행을 보여 준다.
- 강한 상징(불꽃)을 하나 정해 일관되게 쓴다.

### 로그인 보상 비판
- 접속만 해서 받는 보상은 들어왔다 바로 나가게 만들 수 있다.
- 우리 사이트는 '쉬는 시간에 들르는 습관' 자체가 목적이라 접속 = 핵심 행동이다. 그래서 출석 보상은 그대로 유효하다.
- 다만 보상을 사이트 안에서 쓰는 것(프로필 꾸미기)으로 연결해서, 받은 걸 자랑하러 다시 오게 한다.

## 적용한 결정

| 원칙 | 우리 사이트 |
|---|---|
| 평소엔 짧게, 기념일만 크게 | `MILESTONES`(3·7·14·30·50·100·150·200·365)나 보상 해금 날만 빛줄기·색종이·'보상 도착!' 딱지·보상 카드가 차례로 나옴 |
| 진화 | 불꽃: 1~6 주황 → 7~29 붉은 주황 → 30~99 금빛 → 100~ 푸른 불꽃. 헤더 버튼·프로필 칩·순위도 같은 단계 색 |
| 완벽한 연속 | `users.st_pf`. 방패를 쓰면 0, 끊기면 1로 다시 시작. 3일 이상이면 금빛 후광(헤더 버튼은 금색 테두리) |
| 개근 주 | 월~금 모두 출석이면 이번 주 도장 줄이 금빛 띠, 금요일에 '이번 주 개근!' |
| 이어진 날 띠 | 이번 주 줄·달력에서 전날과 이어지면 사이를 띠로 연결(방패로 지킨 날은 파란 띠) |
| 다음 목표 | 연속·누적 중 가장 가까운 다음 보상과 남은 날을 축하 창·출석 창에 항상 표시 |
| 보상 종류 | 스티커 · 프로필 사진 · **배경 색**(불꽃·노을·오로라·은하수·금빛, 그라디언트) · **칭호**(이름 아래 · 출석 순위에 표시) |
| 두 갈래 보상 | 연속(최고 기록) + **누적 출석일**. 기록이 끊겨도 꾸준히 오면 받게(초반 이탈 방지 + 공정함) |
| 지위 | 30일 이상 프로필 큰 아바타 금빛 테두리, 칭호, 순위에 불꽃 색 단계 |

## 하지 않은 것 (이유)
- **알림·푸시:** 학교 태블릿은 공용이고 휴대폰을 걷어서 의미가 없다.
- **공유 카드:** 친구끼리만 쓰는 사이트라 프로필이 그 역할을 한다.
- **목표 정하기(7·14·30일 약속):** 화면이 하나 더 늘어서 보류. 원하면 다음에.
- **친구 연속 기록(둘 다 출석해야 이어짐):** 서버 표가 하나 더 필요하다. 반응을 보고 결정.

## 고칠 때 주의
- 보상 목록은 `public/js/att-rewards.js` **한 곳**. 서버(`lib/attend.js`)와 화면이 같이 쓴다.
- 이모지는 학교 태블릿에서도 보이는 2019년 이전 것만 쓴다.
- 축하 창은 열 때 맨 아래 버튼에 초점이 가면서 내려가므로, 연 뒤 `scrollTop = 0`으로 올린다.
- CSP가 `style=""`을 막는다. 진행 막대·색종이 위치는 `style.setProperty`로 넣는다.
- 클래스 이름이 사이트 공용 클래스와 겹치면 모양이 깨진다(`.mini`·`.hd`·`.dot` 사고).
  - 출석 쪽은 `att-*`·`fsm`·`wd`·`ch` 같은 이름을 쓴다.
