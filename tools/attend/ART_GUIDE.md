# 출석 그림·불꽃 아트 가이드 (학습 기록)

2026-10-23 하율 피드백 두 번이 이 문서의 출발점이다.
1. "왜 자꾸 이모지로 만드냐. 싹다 따로 만들어라."
2. 직접 그린 첫 버전을 보고 "진짜 개짜친다. 학습 먼저 하고 전에 학습한 것도 끌고 와서 적용해라."

새 그림을 만들기 전에 이 문서와 `tools/skins/CHARACTER_GUIDE.md`, `tools/skins/ANIMATION_GUIDE.md`를 먼저 읽을 것.

## 1. 실패 원인 분석 (첫 직접 그림 버전)

| 증상 | 원인 |
|---|---|
| 클립아트처럼 납작함 | 면 하나에 단색 + 같은 굵기 남색 선만 씀. 깊이·광택·그림자 톤이 없다 |
| 사이트와 따로 놂 | 하율이 고른 로고는 **3D 젤리 G**다: 두께, 위→아래 그라디언트, 흰 광택 띠, 흰 스티커 판, 딱딱한 그림자. 첫 버전에는 이 언어가 하나도 없었다 |
| 캐릭터가 안 귀여움 | 이미 학습한 `CHARACTER_GUIDE`를 적용하지 않았다: 남색 외곽선, 동그란 점 눈, 넓은 이마 무시 |
| 불꽃이 평범함 | 대칭 물방울 3겹뿐이다. 불꽃 특유의 S자 흐름, C자로 파인 가장자리, 갈고리 끝, 떨어져 나간 불씨가 없다 |
| 불꽃 애니메이션이 싸 보임 | 늘였다 줄였다(scale)만 반복했다. 불은 **위로 흘러가고, 바람에 좌우로 밀리고, 끝이 떨어져 나간다** |

## 2. 조사로 배운 것

- **듀오링고 shape language**
  - 아주 적은 수의 의도된 도형으로 만든다.
  - 둥글고 친근한 형태, 굵고 밝은 색을 쓴다.
  - 핵심 디테일만 과장하고 나머지는 뺀다.
  - 실루엣이 읽히도록 도형 사이 공간을 둔다.
- **음영 (pixnote shading)**
  - 빛은 한 방향(왼쪽 위)으로 고정한다.
  - 그림자는 빛 반대쪽(오른쪽 아래)에만 둔다. 가장자리를 고르게 어둡게 하는 'pillow shading'은 초보 실수다.
  - 48px 크기에서는 3~4톤(밝은 면·기본·그림자·깊은 그림자)이 적당하다.
  - 그림자는 채도를 유지한 채 명도를 낮추고, 색상을 따뜻한 쪽 → 붉은 쪽 → 보라 쪽으로 옮긴다. 채도를 빼면 탁해진다.
  - 하이라이트는 흰색에 가깝게, 작게, 빛 받는 쪽에만 둔다. 보석·금속은 아주 작고 날카롭게.
- **불꽃 그리기 (VFX Apprentice)**
  - 아래는 두툼하고 위로 갈수록 가늘어진다.
  - 큰 S자 흐름으로 실루엣을 잡는다.
  - 가장자리를 C자로 파서 '치약 덩어리'처럼 보이지 않게 한다.
  - C자가 만나는 곳은 날카로운 갈고리 끝으로 만든다.
  - 갈고리·C자 크기를 일부러 다르게 한다. 너무 반듯하면 가짜 같다.
  - 안쪽 선은 바깥 흐름을 따라간다.
- **불 움직임**
  - 열은 위로 흐른다. 불은 바깥으로 부풀지 않고 위로 흘러간다(부풀면 폭발처럼 보인다).
  - 바람 세기가 바뀌면 좌우로 밀리는데, 이게 일렁임이다.
  - 한 사이클은 1초 이상이고, 반복이 눈에 띄지 않게 한다.
  - 끝 조각은 떨어져 나가 위로 올라가며 작아지고 사라진다.
- **스티커 (다이컷)**
  - 그림 둘레를 따라 흰 판을 두르고, 판 밖에 얇은 테두리와 딱딱한 그림자를 둔다.
  - 가는 돌기는 판에 묻히니, 작은 크기에서는 실루엣을 단순하게 한다.

## 3. 예전에 학습해 둔 것 (다시 적용)

- **CHARACTER_GUIDE (베이비 스키마)**
  - 찹쌀떡 머리, 넓은 이마(눈은 세로 중심보다 아래).
  - 눈은 세로 타원 + 작은 하이라이트 1개. 색은 `#3b2a2e`(순검정 금지).
  - 코·입은 아주 작게, 입은 ω.
  - 볼터치는 분홍 .5.
  - **외곽선은 검정·남색 금지 → 몸 색을 진하게 한 색.**
  - 파스텔, 잔선 최소, 소품은 하나.
  - 56px에서도 눈·볼이 보이는지 렌더링으로 확인한다.
- **ANIMATION_GUIDE (12원칙)**
  - 예비동작 → 동작 → 겹침(부위마다 늦게) → 천천히 끝나기 → 감쇠하는 흔들림.
  - transform·opacity만 움직인다.
  - '동작 줄이기' 설정을 존중한다.
- **사이트 언어**
  - 스티커 보드: 남색 굵은 선 + 딱딱한 그림자 + 마스킹테이프 + 살짝 기울기.
  - 시간표 과목 아이콘(남색 선 + 파스텔)은 통과했다.
  - 애플 이모지는 "짜친다"고 했고, 미니멀하고 딱딱한 것도 "짜친다"고 했다.
  - 로고는 3D 젤리 G를 골랐다. 색은 너무 진하지 않게.

## 4. 적용 규칙

### 물건 보상 (스티커·메달·트로피 등) — 로고와 같은 '젤리 스티커'
1. **두께:** 같은 실루엣을 오른쪽 아래로 (1.6, 3) 밀어 진한 색으로 깐다. 로고 G의 두께 표현과 같다.
2. **면:** 위가 밝고 아래가 진한 세로 그라디언트를 쓴다.
3. **그림자:** 오른쪽 아래에 한 톤 더 진하고 색상을 옮긴 그림자 면을 따로 둔다.
4. **광택:** 왼쪽 위에 둥근 흰 광택 띠(투명도 .85)를 하나 둔다. 보석·금속은 작은 반짝 점을 더한다.
5. **외곽선:** 남색 `#173048`. 로고·사이트와 같다.
6. **판:** 화면에 놓일 때 CSS로 흰 다이컷 판 + 딱딱한 그림자를 두른다(`.stkr`).

### 캐릭터 보상 (프로필 사진) — CHARACTER_GUIDE 그대로
- 찹쌀떡 얼굴, 몸 색을 진하게 한 외곽선, 세로 타원 눈, ω 입, 볼터치.
- 둥근 칸 안에서 얼굴이 꽉 차게 그린다.
- 밝은 쪽 위 광택 + 아래 그림자 톤으로 젤리 느낌을 준다.

### 불꽃
- S자로 오른쪽으로 살짝 기운 실루엣. 갈고리 끝 3개는 크기를 서로 다르게 한다.
- 가장자리는 C자로 판다. 떨어져 나간 불씨 2개를 둔다.
- 4겹: 바깥 진한 주황 → 가운데 주황 → 속 노랑 → 심지 흰빛.
- 남색 외곽선 + 두께(오른쪽 아래 진한 판) + 왼쪽 광택.
- 단계 색: 주황 → 붉은 주황 → 금빛 → 푸른 불꽃.

### 불꽃 애니메이션 — 접속했을 때 한 번만, 끝나면 가만히
- 총 길이 약 1.8초.
1. **불붙기(예비동작):** 아래로 살짝 눌렸다가 솟는다.
2. **바람 두세 번:** 왼쪽 → 오른쪽 → 왼쪽으로 기울고 진폭이 줄어든다. 바깥 → 가운데 → 속불 순서로 늦게 따라온다(겹침).
3. **끝 조각이 떨어져 나감:** 불씨가 위로 올라가며 작아지고 사라진다.
4. **천천히 제자리:** 마지막에 멈추고, 그 뒤로는 움직이지 않는다.
- 크기 키우기만으로 일렁이는 흉내를 내지 않는다. 기울기·밀림·흐름으로 표현한다.

## 5. 정가운데 맞추기 (2026-10-23 "정 가운데가 아니야" 지적)
- 그림마다 두께(오른쪽 아래)·반짝이 때문에 그려진 범위가 viewBox 가운데에서 벗어남 → 칸 안에서 한쪽으로 치우쳐 보였음.
- 해결: 헤드리스 브라우저 `getBBox`로 그림마다 실제 범위를 재서(반짝이 `.tw`는 장식이라 제외), 그 중심에 맞춘 정사각 viewBox(`att-art.js VB`)를 씀. 모든 그림이 같은 크기·정가운데.
- 그림을 고치거나 새로 그리면 VB를 다시 잴 것. 그림을 담는 칸(svg)이 칸(그리드 셀)보다 크면 넘친 만큼 한쪽으로 밀리니 칸보다 작게.
- 불꽃 숫자는 불꽃 몸통 안(높이 66%)에 두고, 세 자리면 글씨를 줄임.

## 8. 3차 (같은 날, 하율: "내 사이트랑 컨셉에 맞게")
- 교훈: 예쁜 것의 기준은 **이 사이트의 컨셉** — 파란 톤 · 스티커 · 로고(흰 원 씰 + 남색 테 + 젤리 G + 별 + 마스킹테이프) · 사이트 캐릭터 테마 친구들. 바깥 유행·실사풍 풍경은 사이트와 따로 놂.
- 프로필 사진 = 로고와 같은 **씰 스티커**(흰 판·남색 테·딱딱한 그림자·왼쪽 위 광택) 안에 **사이트 캐릭터**(`mascots.js` MASCOT 그대로) + 배경·소품: 하늘 강아지(10) · 벚꽃 토끼(누적15) · 달밤 양(30) · 왕관 곰(100) · 바다 고래(누적120) · 은하수 고양이(365). `seal()`.
- 스티커도 사이트 소재로: 체리 → 알람 시계(첫 화면 시계), 미러볼 → 종(쉬는 시간 종), 150일 = **G 로고 씰**(마스킹테이프·별), 나비는 90일로.
