# 캐릭터 애니메이션 가이드

왼쪽 아래 마스코트(`#mascot`) 움직임은 `public/css/style.css`의 '왼쪽 아래 캐릭터' 구간(`m-*` 키프레임)에 있다.
SVG 부위 클래스는 `mascots.py`가 붙인다: `.msh` 그림자 · `.mb` 몸 전체 · `.mbo` 몸통 · `.mh` 머리 · `.me` 눈 · `.ma` 흔드는 팔 · `.mt` 꼬리 · `.ms` 고래 물줄기 · `.mk` 반짝이.

## 근거
- 디즈니 애니메이션 12원칙(찌그러짐과 늘어남, 예비동작, 따라오는 동작·겹침, 천천히 시작·끝, 호, 보조 동작, 타이밍, 과장, 매력).
- web.dev 'high-performance CSS animations': transform·opacity만 움직이고, 자주 바뀌는 요소에만 `will-change`로 층을 분리.

## 적용 규칙
1. **숨쉬기(대부분의 시간)**: 아주 작은 늘고 줄기(±2%). 9초 중 절반 이상은 이것만 — 쉬는 시간용 사이트지만 계속 시선을 끌면 피곤함.
2. **점프는 예비동작부터**: 찌그러짐(1.09, .9) → 위로 늘어남(.94, 1.07) → 꼭대기에서 원래 모양 → 착지 찌그러짐(1.1, .88) → 반대로 살짝 출렁 → 정지. 가로·세로를 반대로 바꿔 부피가 유지되는 느낌.
3. **천천히 시작·끝**: 구간마다 cubic-bezier를 따로 줌(올라갈 땐 빨리 출발해 꼭대기에서 느리게, 떨어질 땐 점점 빨라짐).
4. **겹침 동작**: 머리(`.mh`)는 몸보다 늦게 기울고 늦게 멈춤. 그림자는 뜰 때 작고 옅어짐.
5. **보조 동작**: 눈은 5.3초 주기로 몸(9초)과 어긋나게 → 매번 다른 조합. 한 번 깜빡, 옆 보기, 두 번 깜빡.
6. **손 흔들기**: 살짝 반대로 젖혔다가(예비동작) 2~3번 흔들고 천천히 내림.
7. **몸 없는 캐릭터**: 유령은 호를 그리며 둥실, 슬라임은 말랑 출렁, 고래는 물결 따라 기우뚱 + 물줄기.
8. **반응**: 테마를 고른 순간 한 번 깡충 인사(`.m-hello` — `.hi`는 메뉴 항목 클래스라 겹쳐서 크기가 줄던 문제 있었음).
9. **버튼 위에서 떨어지기·올라타기**(`.m-drop`·`.m-rise`, `app.js`의 `#apps` IntersectionObserver가 `at-svc`가 바뀔 때 붙임): 홈에서 서비스 버튼이 보이면 캐릭터가 **크기 그대로** 버튼 위에 앉음(위치만 `.mascot` transform으로 이동, 말풍선·기호 같은 덧붙임 없음).
   - 놀람(take) = 예비동작(찌그러짐·눈 가늘게) → 반응(늘어남·눈 크게) → 잠깐 멈칫(moving hold).
   - 떨어지기: 놀람 뒤 .32초부터 중력처럼 가속(ease-in) 낙하, 낙하 중 몸은 늘어나고 팔은 허우적, 머리는 늦게 따라와 위로 뜸 → 착지 순간 크게 찌그러짐(머리는 관성으로 계속 내려감) → **다시 튀어 오르지 않고** 천천히 펴짐(통제된 착지 후 회복).
   - 올라타기(놀람 없음 — 2026-10-23 사용자 결정): 버튼과 함께 밀려 올라가며(감속 ease-out) 눌렸다 늘어남 → 발을 축으로 휘청, 진폭은 8°→6°→3.5°→2°→0.8°로 줄어듦, 각 흔들림은 천천히 시작·끝. 머리는 몸과 반대로 늦게 기울고(겹침), 팔은 균형 잡듯 휘저음.
   - 근거: Toon Boom 'take' 분석(예비동작=찌그러짐, 반응=늘어남), 12원칙(중력 타이밍·겹침·천천히 시작/끝).

## 성능 규칙
- transform·opacity만 애니메이션. `#mascot`은 `will-change:transform` + `contain:layout style`로 자기 층(paint 포함은 점프할 때 위가 잘려서 뺌) → 캐릭터가 움직여도 페이지 나머지는 다시 그리지 않음.
- 고정(fixed) 배경 이미지 금지 — 스크롤마다 전체 다시 그리기 유발. 스티커는 고정 위치 요소로.
- 다른 탭·앱을 볼 땐 `html.away`로 일시정지. '동작 줄이기' 설정이면 모두 정지.
- 마스코트 그림(`js/mascots.js`)은 캐릭터 테마일 때만 불러옴.
